Design notes

Network
  • One subscription: shared by all three departments.
  • Separate subnets: reserve addresses for VMs and printers.
  • NSG: attached to the VM subnet. Default rules only; internal traffic allowed.
  • NAT + static public IP: outbound path for the VM subnet.
  • Printer subnet: no NSG or NAT; automatic outbound access disabled.
Virtual machines
  • One per department: Estates, Finance and Operations.
  • System: Windows Server 2022.
  • Size: Standard_D2s_v4. Standard LRS system disk.
  • Addresses: dynamic private IPs. No VM public IPs.
  • Remote access: listed under To do.
Password protection
  • Input: vm_admin_password. Supplied at deployment; Terraform does not generate it.
  • sensitive = true: hides the password in normal Terraform output.
  • State + saved plans: still contain the password. Keep them private.
  • GitHub: state, saved plans and local variable files excluded.
File storage
  • Azure Files: managed shares; no dedicated file-server VM.
  • Accounts: one per department. Standard GRS.
  • Hot tier: frequent access. Quota: 500 GiB per share.
  • Cost tracking: used department tags.
  • Access: public storage addresses. No private endpoints.
  • Permissions: Entra ID authentication and share permissions listed under To do.
