Azure network design

Shared networking and managed file storage for Estates, Finance and Operations in Azure UK South. Solid boxes show Terraform resources; dashed lines and boxes show intended printer access.

Departments and shared printing

Each department has its own storage account and a 500 GiB Hot file share. Department tags identify storage costs within the shared subscription. Printer access is part of the intended design.

Design decisions

Shared subscription: keeps the network and department storage together. Separate storage accounts and department tags support cost tracking without extra subscriptions.

Network: separate subnets reserve addresses for VMs and printers. The printer subnet has a security group with default rules. The VM subnet uses a NAT gateway and static public IP for outbound connections.

Managed storage: Azure Files removes the need for a dedicated file-server VM. Each share uses the Hot tier for frequent access, a 500 GiB quota and Standard storage with geo-redundant replication.

Current status

Terraform validation and a live plan passed on 29 October 2026: 13 resources to add, none to change or destroy. These changes have not been applied.

Microsoft Entra ID authentication, file-share permissions and a print service are not configured. The printer subnet alone does not provide printing.

The private DNS zone remains in Terraform and is omitted from these diagrams because its removal is planned. The resource group outputs all reference the first resource group. See design decisions and limitations.
